# native gate: independent composition, not a repaired producer

the original two monolithic lifecycle producers remain failed. their partial
printed assertions are history, not acceptance of a process that later failed.
`HANDOFF.md` and the orthogonal partial report retain that original scope.

`complete.py` composes successful original literal/random leaves with two
separate, successful acquisitions:

- `lifecycle.cpp`: a fixed, nonallocating event log; observers call scalar
  `selectIndex`, never construct another observed item. capacity is reserved
  before arming. same-pool observation/mutation occurs after native vector
  insertion finishes; destructor reentry during clear targets a different pool.
  this avoids recursive selected-item destruction and a single overwritten
  observation flag. eight exact current/reference traces cover append full
  expressions, post-callback total reads, container copies, two move-throw
  stages, return-copy exceptions, cross-pool reentry and returned-list lifetime.
- `scalar.cpp`: successful integer-only checks for empty/random consumption,
  index uniqueness, retry order and unsigned seed wrap. these replace reliance
  on assertions printed by the failed monoliths; neither old program is rerun.

a compiled cached-total mutant fails the post-callback observation. independent
object-identity/move/destructor conservation checks supplement trace parity.
named-result nrvo eligibility is source-traced; item/caller lifetimes are
observed. the fixture does not pretend that vector's optional elision has a
publicly observable constructor count.

the old inventory file is retained byte-exact before catalog refresh. only its
metadata path may use that retained version; compiler/headers/objects/sdk bytes
must match their original admitted values. this is not a renewal of the old
live/global source guard. original optimization flags stay unchanged; broad
nonfinite/subnormal/overflow probes remain diagnostics, not ieee expectations.

no rust implementation or game adoption is established by this native gate.
