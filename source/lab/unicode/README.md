# compiled unicode laboratory

run from the repository root:

```sh
python3 source/lab/unicode/run.py --output build/unicode-lab/cpp-final
python3 source/lab/unicode/run.py --output build/unicode-lab/rust-final \
  --define STAR_USE_RUST_UNICODE \
  --archive build/unicode-rust/target/release/libstar_engine_ffi.a \
  --reference-report build/unicode-lab/cpp-final/report.json
```

Rust requires a separate CPP-only observation report. this closes same-process
reference contamination: real String/Encode dependencies can call the active
Unicode symbols even while a namespace-frozen hex facade is running. a stable
64-bit FNV observation stream covers raw values, encoded bytes and all string/error
outcomes, excluding receipts/ABI-only probes; candidate digest must equal the
CPP-only executable's digest. digest collisions remain a finite-check limitation.

the runner freezes **all** `StarUnicode.cpp` and `StarUnicode.hpp` from
`b136ed4ba23e59edac204c0a18377a13ae267c24`. reference adaptation changes only
the namespace/import and its local header include. actual Encode, ByteArray,
String, Maybe, Config and Bytes dependencies are entry-revision gated, not
reimplemented. both sides use identical compiler flags from the existing native
reference recipe. generic iterators stay byte-identical; they are not port claims.

the harness exercises all ten compiled public functions, including allocating
hex/string facades, exact errors and precedence, input/output alias final state,
capacity/tail canaries, and zero-consumption untouched outputs. every codepoint
0..0x110000 is encoded at capacities 0..6; frozen generated bytes additionally
exercise validate/length/decode in bounded and sentinel modes. literal UTF8/UTF16
anchors, seeded malformed buffers and hex text are independent checks, not just
round trips. a protected page checks short NUL-terminated and bounded reads; a
fault fails the run and never counts as a successful negative control.

Rust mode also probes ABI status/output transactionality and exact ten-counter
deltas, including semantic errors and no internal-helper double counting.

five isolated real algorithm mutants must compile and exit **1** from comparison:
NUL termination, replacement consumption, capacity partial writes, pair arithmetic,
and invalid hexadecimal nibble handling. the last modifies the real Encode
dependency shared by both sides and must be rejected by an independent literal
anchor. provenance and CLI corruptions are separate controls; missing Rust
receipts must also exit 1.

`before.json`/`after.json` bind checker, frozen/active sources, compiler, all actual
compiler-reported transitive headers (including SDK/standard/vcpkg), existing core
objects, dependency archives, and selected Rust archive. the runner packages
existing native OBJECT files into its own archive and **never rebuilds shared
native/Cargo outputs**. the parent must supply the native build/source freshness
seal; hashing old objects and current source alone cannot establish that link.

reports are finite component equivalence evidence, not game/screenshot,
performance, other-platform, whole text subsystem or iterator-port evidence.
