# json-path grammar lab

scope: only the two compiled `StarJsonPath.cpp` grammars. public header and generic traversal stay native. finite tests are not universal equivalence, game, platform, allocation-fault, or performance evidence.

## replay

```sh
python3 source/lab/json-path/run.py --output build/json-path-lab/cpp-final
python3 source/lab/json-path/run.py --output build/json-path-lab/rust-final --define STAR_USE_RUST_JSON_PATH --archive build/jsonpath-rust/target/release/libstar_engine_ffi.a --reference-report build/json-path-lab/cpp-final/report.json
```

no Cargo/native project build is performed. runner consumes existing real native core/extern objects from the baseline reference build and only the kernel worker's isolated Rust archive. source/header snapshots are complete `356eeb9bc92cc0c20259b06918aade0c43326d67`; only namespace/include adaptation is accepted, independently regenerated from git before each run. fallback bodies and production public header must remain byte-for-byte frozen. real String, Unicode iterators, numeric lexical conversion, Json and allocating dependencies are used, not local substitutes.

reports bind source/checker/compiler/dependencies/native objects/archive/binary with SHA256 before and after execution. concurrent mutations cause a rejected report rather than weakened guards. CPP r3 correctly rejected concurrent `StarVersion.cpp.o` mutation while parent built native code; Rust r2 then had no CPP r3 report to consume. these are infrastructure rejection, not candidate mismatch; earlier CPP r2/Rust r1 passed.

39,460 generated/literal cases compare each returned type, complete buffer bytes, UTF8 iterator byte offset, complete exception bytes via `printException(e, false)` (including embedded NUL) and partial/error state. Parent added a literal NUL-suffix error anchor and an isolated old-`what()` harness mutant that MUST fail that anchor; C-string truncation is not credited as full error coverage. empty input, embedded NUL, Unicode, escaped tildes/slashes, malformed escapes/brackets, empty/zero-prefixed/overflow/numeric-sign segments, trailing dots, adjacent brackets, nonzero start, shortened end and buffer/diagnostic-path aliases with separate live iterator storage are included. Parent removed the earlier verifier's unjustified no-growth iterator-after-clear assumption: `String::clear` clears its underlying `std::string`, so storage retention alone is not a language-level iterator-validity guarantee. New alias cases exercise partial-path error formatting without invalidating iterators; no frozen algorithm, expected literal, or production source was changed. C and en_US.UTF-8 locales are exercised when available. bounds that make the frozen algorithm step past storage are excluded.

independent anchors: RFC 6901 section 5 (`https://www.rfc-editor.org/rfc/rfc6901#section-5`), RFC 6902 add-to-array (`https://www.rfc-editor.org/rfc/rfc6902#section-4.1`); real production Json query, pointer get/add/remove, empty traversal identity. independent expected strings are literal, not generated by the candidate.

candidate observations are emitted as a length-delimited ordered binary stream; separate CPP-only process produces its own stream. runner compares SHA256 plus finite FNV digest/count, so an active candidate cannot silently contaminate both sides of the in-process oracle. paired deliberately wrong reference/candidate error text passes local differential comparison but MUST fail the independent ordered-stream identity check. genuine candidate grammar mutants change escape zero/one, dash/numeric classification, empty brackets, digit range, and error text; all must fail with a COMPARISON diagnostic. corrupted snapshot/adaptation, wrong CLI inputs, corrupted independent digest, and suppressed receipts are also rejected.

Rust-only direct ABI tests check exact callback streams for empty input, ordinary keys, numeric/dash short-circuit, both tilde escapes, empty brackets, all five grammar errors; every callback abort prefix leaves both outputs untouched and counts exactly once. validators cover unknown kind, missing callback, null/misaligned/overlapping/overflowing outputs before callbacks. nullable context, nested reentry and per-thread receipts are exercised. receipt-suppression control is required.

limits: C++ exception identity relay is source-traced, not fault-injected. OOM and error-format allocation timing are untested. contained panic is not injected. no malformed raw-pointer validity claim beyond the ABI's enumerable checks. no screenshot/game/platform/performance claim. parent must independently replay final source-bound reports and verify baseline native object freshness against its build seal.
